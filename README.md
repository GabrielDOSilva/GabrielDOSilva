## 📌 Projetos

### 🛒 CRUD Produtos

API REST desenvolvida com Java e Spring Boot para gerenciamento de produtos, seguindo arquitetura em camadas e boas práticas de mercado.

**Funcionalidades**

| Recurso | Descrição |
|---|---|
| ✅ Cadastro | Criação de novos produtos |
| 🔍 Consulta | Listagem geral e busca por ID |
| ✏️ Atualização | Edição de produtos existentes |
| 🗑️ Exclusão | Remoção de produtos |
| 📄 Paginação | Resultados paginados |
| 🔀 Ordenação | Ordenação customizável |
| 🛡️ Validação | Validação de dados de entrada |
| ⚠️ Exceções | Tratamento global de exceções |
| 📦 DTOs | Separação entre entrada e saída de dados |
| 💾 Persistência | JPA + MySQL |

**Arquitetura em camadas**

```
Controller → DTO → Service → Repository → MySQL
```

**Stack:** Java · Spring Boot · Spring Data JPA · MySQL · Maven

[🔗 Ver repositório](https://github.com/GabrielDOSilva/crud-produtos)
